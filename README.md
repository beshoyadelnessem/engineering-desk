# Besho's Engineering Desk

Personal reference site for Besho (Mechanical Design & Production Eng., Faculty of Engineering, Zagazig University).

- **Engineer** – 11 calculators, each with a live drawing and sourced formulas: spur gears, shaft sizing, limits & fits (ISO 286), torsion, beam bending, axial & thermal, section properties, sheet-metal bend, speeds & feeds, projectile motion, unit converter.
- **University** – study notes (drawing, stress, testing, section tables, dynamics, machine design, metal cutting, vibration), course files by year/subject, TA desk (subjects, notes, sections timetable) and links to other departments.

Everything is one self-contained `index.html` (no build step). Open it locally or serve it with GitHub Pages.
`build.py` + `src/` regenerate it from the base page (`desk.html`).
